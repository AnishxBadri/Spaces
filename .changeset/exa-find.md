Exa finds companies in Ask. The manifest declares Exa's hosted MCP server with its fast search tools only (websets stay the watch's), keyed with the workspace search key in `x-api-key`; with the web in scope a question such as "rental software startups in India" is searched through it and answered as a table of companies to add or file into the space. Exa is never called from a sensitive scope. Needs sdk ^1.5.
